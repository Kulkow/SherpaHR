# Несогласованности

| ID | Ожидание и фактическое поведение | Влияние и способ согласования |
|---|---|---|
| D-01 | Справка API обещает все задачи проекта, а схема и формы допускают задачу без исполнителя. В списке `INNER JOIN users` по `assignee_id` отбрасывает такие записи. Счётчик проектов считает их, карточка по ID открывается | У Анны в отчётности счётчик показывает 3, список API содержит №5 и №6, карточка №7 читается по ID. В её обсуждении есть просьба вмешаться. После локального добавления задачи без исполнителя строка исчезнет при повторной загрузке списка. Убрать соединение с пользователем из запроса списка, поскольку его столбцы не используются. [API](../api.md), [Application.php](https://github.com/SherpaRPA/SherpaHR/blob/d85eb5e76bd0c839798ec55d21c7f0745b6f995f/backend/src/Application.php), [app.ts](../../frontend/src/app.ts) |
| D-02 | Интерфейс ограничивает название, описание и комментарий по длине строки HTML: 200, 5000 и 2000 кодовых единиц UTF-16. API ограничивает поля соответственно 200, 10000 и 5000 байт UTF-8 | Некоторые тексты браузер пропускает, а API отклоняет. Другие тексты подходят API, но превышают предел поля формы. Согласовать единицу измерения, пороги и подсказки формы с серверными правилами. [Шаблон](../../frontend/src/app.html), [API](../api.md), [валидация API](https://github.com/SherpaRPA/SherpaHR/blob/d85eb5e76bd0c839798ec55d21c7f0745b6f995f/backend/src/Application.php) |
| D-03 | API хранит срок с секундами, UI показывает и редактирует срок до минуты. При сохранении любого поля UI отправляет весь черновик, добавляя к сроку `:00Z` | Срок, заданный через API с ненулевыми секундами, может измениться при правке заголовка. Сохранять исходный срок до явного изменения поля или отправлять только изменённые поля. [API](../api.md), [app.ts](../../frontend/src/app.ts) |

D-01 подтверждено вызовами API через PHP CLI на новой SQLite в памяти. D-02 и D-03 установлены сравнением исходного кода UI и API.
