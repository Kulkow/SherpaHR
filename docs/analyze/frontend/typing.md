# Типизация входов и выходов

| ID | Граница | Проблема | Предлагаемое изменение |
|---|---|---|---|
| T-01 | Выход HTTP-клиента | `response.json()` передаёт непроверенное значение. `as T` подтверждает только ожидание вызывающего кода. Успешный ответ без `data` формально вернёт `undefined` как `T`, а повреждённый массив задач проявится при фильтрации или рендеринге. [api.ts](https://github.com/SherpaRPA/SherpaHR/blob/d85eb5e76bd0c839798ec55d21c7f0745b6f995f/frontend/src/api.ts#L7-L15), [фильтр](../../../frontend/src/app.ts#L89-L92) | Принимать разобранный JSON как `unknown`, проверять конверт ответа и нужную форму данных на границе API |
| T-02 | Вход HTTP-клиента | Произвольные `path`, `method` и `data?: unknown` не связывают маршрут с формой запроса. Обязательность `version` при PATCH и структура тела комментария существуют только в конкретных вызовах. [api.ts](https://github.com/SherpaRPA/SherpaHR/blob/d85eb5e76bd0c839798ec55d21c7f0745b6f995f/frontend/src/api.ts#L7-L12), [вызовы записи](../../../frontend/src/app.ts#L127-L166) | Добавить узкие методы для чтения, создания, обновления и комментария. Ввести типы тел запросов, оставив общий транспорт внутренним |
| T-03 | Ввод пользователя | `$any($event.target)` отключает проверку Angular для значения селектора. `Number(value)` может дать `NaN` или ID вне каталога, если появится неожиданный вариант. Текущие три значения заданы статически и корректны. [app.html](../../../frontend/src/app.html#L4-L8), [app.ts](../../../frontend/src/app.ts#L59-L67) | Использовать типизированный элемент селектора или привязку числового ID формы и сверять его с каталогом |
| T-04 | Срок и черновик | Модель `Task` хранит UTC или `null`, а форма использует локальный формат поля без зоны и пустую строку. При сохранении отправляются все поля, и неизменённый срок с ненулевыми секундами сериализуется с `:00Z`. [models.ts](https://github.com/SherpaRPA/SherpaHR/blob/d85eb5e76bd0c839798ec55d21c7f0745b6f995f/frontend/src/models.ts#L3-L6), [app.ts](../../../frontend/src/app.ts#L94-L108), [преобразование в запрос](../../../frontend/src/app.ts#L135-L141) | Выделить тип черновика и функции преобразования. Отправлять срок только при его изменении либо сохранять исходное значение до явной правки |
| T-05 | Лимиты полей формы | `maxlength` использует кодовые единицы UTF-16, сервер считает байты UTF-8. Лимиты описания и комментария также отличаются численно. Поэтому интерфейс может принять ввод, отклоняемый сервером, или ограничить допустимый запрос. [app.html](../../../frontend/src/app.html#L51-L65), [контракт API](../../api.md), [расхождение D-02](../inconsistencies.md) | Использовать согласованные ограничения и проверять длину UTF-8 в форме. Серверная проверка остаётся обязательной |
