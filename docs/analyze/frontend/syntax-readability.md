# Синтаксис, читаемость и именование

| ID | Наблюдение и последствия | Предлагаемое изменение |
|---|---|---|
| R-01 | **Плотная разметка.** В одной строке смешаны управляющие блоки Angular, форма и вложенная разметка. Это особенно заметно в таблице задач, выборе исполнителя и форме комментария. [app.html, строки 29–39](../../../frontend/src/app.html#L29-L39), [форма](../../../frontend/src/app.html#L51-L65) | Форматировать элементы, атрибуты и управляющие блоки единообразно, с отступами по вложенности |
| R-02 | **Свёрнутые модели.** В моделях проекта и задачи много полей на одной строке. Простой поиск по имени работает, но при ревью сложнее увидеть, какое поле изменилось и какие поля допускают `null`. [models.ts, строки 1–7](https://github.com/SherpaRPA/SherpaHR/blob/d85eb5e76bd0c839798ec55d21c7f0745b6f995f/frontend/src/models.ts#L1-L7) | Разместить поля многострочных интерфейсов на отдельных строках |
| R-03 | **Названия состояния.** `status`, `search`, `comment`, `project` и `detail` не отличают фильтры и черновики от данных ответа. `generation` используется и для загрузки контекста, и для списка проекта. [app.ts, строки 14–30](../../../frontend/src/app.ts#L14-L30), [загрузки](../../../frontend/src/app.ts#L38-L86) | Использовать имена вроде `statusFilter`, `searchQuery`, `commentDraft`, `selectedProject` и `taskDetail`. Для счётчиков отразить, какие операции они отслеживают |
| R-04 | **Дублирование преобразований.** Преобразование задачи в черновик выполняется при открытии и после сохранения. Выражения для срока эквивалентны для штатных данных, но записаны по-разному. [app.ts, строки 94–108](../../../frontend/src/app.ts#L94-L108), [ответ сохранения](../../../frontend/src/app.ts#L141-L152) | Использовать одно преобразование с типом черновика. Отдельно определить сохранение секунд при редактировании других полей |
| R-05 | **Плотные обработчики.** В одной строке запроса сохранения выбираются путь и метод, а в компактных `catch` и `finally` скрыто управление ошибкой и флагом ожидания. [app.ts, строки 127–174](../../../frontend/src/app.ts#L127-L174) | Вынести выбор операции в типизированные методы API или в понятные именованные значения, разворачивать блоки управления состоянием |

Ревью синтаксиса ограничено чтением исходников. В проекте включены TypeScript `strict` и Angular `strictTemplates`. Скрипт `typecheck` запускает только TypeScript, поэтому проверка Angular-шаблонов требует отдельной сборки. [tsconfig.json](../../../frontend/tsconfig.json), [package.json](../../../frontend/package.json).
