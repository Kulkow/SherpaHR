# Ревью frontend Project Desk

Проверены компонент и шаблоны Angular, HTTP-клиент, TypeScript-модели, стили, конфигурация сборки и прокси. Ревью относится к версии `d85eb5e76bd0c839798ec55d21c7f0745b6f995f`.

| Раздел | Основные выводы |
|---|---|
| [Синтаксис, читаемость и именование](syntax-readability.md) | Длинные строки в шаблонах затрудняют чтение. Преобразование задачи в черновик дублируется |
| [Безопасность](security.md) | Интерфейс не является границей доступа. Dev-сервер слушает все интерфейсы, а переключатель пользователя подходит для локального демо |
| [Входная и выходная типизация](typing.md) | Тип ответа задаёт вызывающий код. Структура JSON в рантайме не проверяется |
| [Архитектура, состояние и интерфейс](architecture.md) | Переключение между проектами во время сохранения может рассинхронизировать список. Ошибка загрузки смешивается с пустым результатом. Фокус при открытии карточки не управляется |

Для v7 приоритетны сохранение исходного срока при правке других полей, корректная синхронизация списка и карточки, обработка ошибок и повторное использование карточки из общего обзора. Отправку нового комментария блокирует ответ 501 на стороне сервера. [Справка API](../../api.md), [ревью backend](../backend/architecture.md).

## Проверки

Выводы о TypeScript, Angular-шаблонах, состоянии и интерфейсе основаны на чтении исходников. Для контраста выбранных цветов выполнен расчёт по значениям из CSS. Сборка и проверка в браузере не выполнялись. Локальных зависимостей `frontend/node_modules` в рабочем дереве нет.
