# Безопасность frontend

| ID | Наблюдение и условия | Меры |
|---|---|---|
| S-01 | **Демо-пользователь выбирается клиентом.** Сервис хранит ID в изменяемом поле и добавляет его в `X-Demo-User`. Это штатное поведение локального демо. Если приложение станет доступно недоверенным пользователям, выбор в UI не обеспечивает идентификацию. [api.ts, строки 3–15](https://github.com/SherpaRPA/SherpaHR/blob/d85eb5e76bd0c839798ec55d21c7f0745b6f995f/frontend/src/api.ts#L3-L15), [переключатель](../../../frontend/src/app.html#L3-L8), [модель backend](../backend/security.md) | Для рабочего развёртывания получать личность из проверенного сервером контекста и продолжать проверять доступ к объектам на сервере |
| S-02 | **Dev-сервер слушает все интерфейсы.** Скрипт `start` использует `--host 0.0.0.0`. При разрешённом сетевом доступе dev-сервер с прокси может сделать локальный API доступным другим участникам сети. Compose отдельно ограничивает опубликованный порт loopback. [package.json](../../../frontend/package.json), [proxy.conf.json](../../../frontend/proxy.conf.json), [compose.yaml](../../../compose.yaml) | По умолчанию ограничить dev-сервер loopback. Использовать сетевой режим только для явного тестирования с другого устройства |
| S-03 | **Архив блокируется в UI для удобства пользователя.** Форма отключает поля и скрывает кнопки, а в методах сохранения проверяются открытый объект и флаг ожидания. Для защиты от записи решающей остаётся проверка архива в API. [app.html, строки 48–66](../../../frontend/src/app.html#L48-L66), [app.ts, строки 127–173](../../../frontend/src/app.ts#L127-L173), [запрет записи в API](https://github.com/SherpaRPA/SherpaHR/blob/d85eb5e76bd0c839798ec55d21c7f0745b6f995f/backend/src/Application.php#L200-L205) | Сохранять серверную проверку при переиспользовании формы. При необходимости дублировать проверку в обработчике UI для согласованного поведения |

Названия задач, имена, комментарии и ошибки отображаются через интерполяцию Angular, а черновики передаются в значения полей формы. В проверенных шаблонах отсутствуют вставка пользовательского HTML и обход санитизации. По исходникам подтверждённого DOM XSS в этих путях не обнаружено. Зависимости на известные уязвимости в рамках этого ревью не проверялись. [Шаблон Angular](../../../frontend/src/app.html).
