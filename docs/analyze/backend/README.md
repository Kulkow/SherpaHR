# Ревью backend Project Desk

Проверены маршрутизатор PHP, API, подключение и инициализация SQLite, схема и smoke-тест. Ревью относится к исходному коду версии `d85eb5e76bd0c839798ec55d21c7f0745b6f995f`.

| Раздел | Основные выводы |
|---|---|
| [Синтаксис, читаемость и именование](syntax-readability.md) | PHP-файлы проходят синтаксическую проверку. В PHP 8.5 есть предупреждение в тесте, а длинные обработчики и позиционные данные усложняют сопровождение |
| [Безопасность](security.md) | Модель доступа годится для локального демо. Для публикации требуется проверяемая идентификация, а большие выборки и обработка ошибок подключения требуют ограничений |
| [Входная и выходная типизация](typing.md) | Явный `null` способен сбросить статус или описание. Формат ответа зависит от строк PDO, а формы входных массивов не задокументированы в коде |
| [Архитектура](architecture.md) | Инициализация берёт блокировку записи на каждом вызове API. Запись комментариев отсутствует, а список теряет задачи без исполнителя |

Для задания v7 приоритетны запись комментариев, корректный список задач и проверки сохранения действующих правил доступа. Для развития приложения важны управление схемой существующей БД, единая обработка ошибок и отделение JSON-контракта от SQL.

## Проверки

- `php -l` выполнен для четырёх PHP-файлов на PHP 8.5.8. Синтаксических ошибок нет. В smoke-тесте получено предупреждение об устаревшем `$http_response_header`. Контейнер проекта использует PHP 8.4. [Dockerfile](../../../Dockerfile)
- Пропуск задачи без исполнителя подтверждён ранее прямыми CLI-вызовами к приложению с SQLite в памяти. [Несогласованности](../inconsistencies.md)
- Остальные выводы основаны на чтении исходников. Полный HTTP smoke-тест при предыдущей попытке остановился при открытии локального сокета. Поведение на нескольких рабочих процессах и под нагрузкой не измерялось.
