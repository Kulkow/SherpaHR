# Системный анализ Project Desk

Project Desk — локальное демо для работы с проектами, задачами и обсуждениями. Анна координирует несколько проектов и сейчас открывает каждый по очереди, чтобы просмотреть задачи и переписку. Цель задания v7 — сократить этот путь и восстановить возможность ответить участникам в карточке задачи.

## Источники и проверка

Анализ основан на состоянии репозитория `d85eb5e76bd0c839798ec55d21c7f0745b6f995f`. Требования и справка — [задание v7](../../task_v7.md), [описание продукта](../product.md) и [API](../api.md). Реализация — [схема](../../backend/schema.sql), [инициализация БД](../../backend/src/Database.php), [маршруты API](https://github.com/SherpaRPA/SherpaHR/blob/d85eb5e76bd0c839798ec55d21c7f0745b6f995f/backend/src/Application.php) и [интерфейс](../../frontend/src/app.html).

Вызовы PHP через CLI на временной SQLite в памяти подтвердили расхождение между счётчиком проекта, списком и карточкой задачи №7. Полный HTTP smoke-тест остановился при создании локального сокета из-за ограничений среды. Сценарии браузера описаны по исходному коду.

В качестве диаграммы данных использована DFD. Целевые правила отбора и приоритета в историях помечены как предложения аналитика.
