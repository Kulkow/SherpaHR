# Нереализованное

| ID | Функция | Текущее состояние | Что требуется для завершения |
|---|---|---|---|
| G-01 | Обзор вмешательств по активным проектам | Есть экран одного проекта с локальным поиском и фильтром. Отбор, объяснение причины и общий список отсутствуют | Реализовать единый обзор с понятными признаками внимания и переходом в карточку. Исправить или учесть пропуск задач без исполнителя, описанный в [D-01](../inconsistencies.md) |
| G-02 | Добавление комментария в карточке | Форма и отправка существуют. После проверок сервер возвращает 501 и не сохраняет текст | Записать текст, автора и время, вернуть созданный комментарий, обеспечить чтение после повторного открытия. [Smoke-тест](../../../backend/tests/smoke.php) ожидает HTTP 201 и сохранение |
| G-03 | Управление проектами и участниками | Демо использует фиксированные записи. API и UI управления отсутствуют | За пределами явных требований v7. При расширении потребуется определить полномочия и жизненный цикл проектов |
| G-04 | Формальная эскалация | Препятствия описывают свободным текстом и статусом задачи | За пределами явных требований v7. Обзор может опираться на текущие поля без введения процесса эскалации |
| G-05 | Рабочая аутентификация | Переключатель передаёт ID демо-пользователя в заголовке | За пределами локального демо v7. Для рабочего использования понадобится отдельное решение об идентификации |

G-01 и G-02 связаны с [заданием v7](../../../task_v7.md) и историями [US-04–US-06](../user-stories/README.md). Остальные пункты описывают текущие границы [продукта](../../product.md).
