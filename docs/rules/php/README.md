# Правила разработки на PHP

Правила применяются к backend Project Desk на PHP 8.4. Прикладной код работает без фреймворка, Composer управляет автозагрузкой и зависимостями разработки.

| Документ | Правила |
|---|---|
| [Стиль и форматирование](style.md) | PSR, PER Coding Style, именование и типизация |
| [Упрощённый DDD и SOLID](design.md) | Инварианты, прикладные сценарии, репозитории и границы абстракций |
| [TDD и PHPUnit](testing.md) | Поведенческие тесты, SQLite в отдельном файле и запуск в Docker |
| [PHPStan](static-analysis.md) | Level 9, конфигурация и порядок проверок |

Перед коммитом прогоняем PHPUnit и PHPStan в Docker. Ориентир для общей команды — `make check` из [архитектуры проверок](../../architecture/delivery-and-quality.md). Описанные конфигурации и команды предназначены для этапа внедрения инструментов.
