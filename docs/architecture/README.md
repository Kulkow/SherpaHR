# Целевая архитектура Project Desk

Project Desk остаётся одним приложением для локального запуска через Docker Compose. Angular отвечает за интерфейс, PHP 8.4 без фреймворка обслуживает JSON API, SQLite хранит данные. Общие термины и правила описываются в словаре предметной области, а HTTP-контракт хранится в одном файле в репозитории.

| Документ | Содержание |
|---|---|
| [Предметная область и контракты](domain-and-contracts.md) | Единый язык DDD, правила доступа, источник JSON-контракта и порядок его изменения |
| [Backend и frontend](implementation.md) | Границы кода, структура каталогов, подход к типизации и инструменты |
| [Docker и проверки](delivery-and-quality.md) | Развёртывание, команды, pre-commit, изолированные тесты и E2E-сценарий |

Это проектное описание. В нём зафиксированы предлагаемые инструменты, пути будущих файлов и команды. Фактическое состояние описано в [справке разработки](../development.md) и [плане v7](../tasks/task-v7-implementation-plan.md).

## Порядок внедрения

1. Сверить словарь и описать существующие операции в OpenAPI. Зафиксировать совместимость полей, статусов и ошибок с текущим Angular.
2. Добавить dev-инструменты, lock-файлы и команды проверок. Восстановить запись комментариев и исправить пропуск задач без исполнителя.
3. Добавить обзор и переход в существующую карточку. Покрыть правила отбора, доступ и критический сценарий тестами.
4. Подключить общие проверки к pre-commit и прогнать Docker-сборку и E2E на изолированной базе.
