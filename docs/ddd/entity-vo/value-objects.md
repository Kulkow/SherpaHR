# Объекты-значения

Объект-значение определяется содержимым и заменяется целиком. Проверки контекста, включая членство исполнителя и состояние архива, выполняются при операции записи.

| Объект-значение | Допустимые значения и равенство | HTTP и хранение |
|---|---|---|
| `UserId`, `ProjectId`, `TaskId`, `CommentId` | В домене положительные целые. Равенство учитывает вид идентификатора и число | Числа в JSON, INTEGER в SQLite. В URL идентификатор разбирается из строки |
| `TaskTitle` | Непустая строка после обрезки краёв. API проверяет предел 200 байт UTF-8 до обрезки. Равенство по сохранённому тексту | `title`, строка |
| `TaskDescription` | Строка, включая пустую, до 10 000 байт UTF-8 до обрезки. Равенство по сохранённому тексту | `description`, строка. При создании по умолчанию пустая |
| `TaskStatus` | Закрытый набор `open`, `in_progress`, `blocked`, `done`. Равенство по коду | `status`, строка. При создании по умолчанию `open` |
| `DueAt` | Валидный момент UTC с точностью до секунды. Равенство по моменту времени. Пустой срок выражается отсутствием значения | `due_at`, строка `YYYY-MM-DDTHH:mm:ssZ` или `null` |
| `UtcTimestamp` | Серверный момент UTC с точностью до секунды. Равенство по моменту времени | `updated_at`, `created_at`, строки UTC |
| `TaskVersion` | Положительное целое. Новая задача получает 1, успешное изменение увеличивает версию на 1. Равенство по числу в контексте одной задачи | `version`, INTEGER. Обязателен в PATCH |
| `CommentBody` | Непустой после обрезки текст, до 5000 байт UTF-8 до обрезки. Равенство по сохранённому тексту | `body`, строка |
| `CommentAttention` | Состояния `none`, `requested`, `resolved`. Равенство по коду | `attention`, строка в SQLite и ответах карточки |
| `AttentionReason` | Коды `comment_attention`, `blocked`, `overdue`, `unassigned`. Равенство по коду. Задача может иметь несколько причин без повторов | Вычисляемый список в ответе обзора. В SQLite не хранится |

По согласованному целевому контракту пропущенное поле PATCH сохраняет прежнее значение. Явный `null` очищает только срок или исполнителя. Для названия, статуса и описания `null` возвращает ошибку 422. [Контракт API](../../api.md).

Имя пользователя, название и описание проекта и флаг архива остаются простыми типизированными полями. Демо задаёт эти поля при инициализации, отдельные пользовательские правила их изменения в v7 отсутствуют.

## Переходы TaskStatus

[Enum `TaskStatus`](../../../backend/src/Domain/Task/TaskStatus.php) предоставляет три метода. `allowTransactions(): array` возвращает список допустимых целевых значений enum. `canTransaction(TaskStatus $target): bool` проверяет принадлежность цели этому списку. `label(): string` возвращает русское название статуса.

| Текущий статус | Допустимые переходы |
|---|---|
| Открыта | В работе |
| В работе | Открыта, Заблокирована, Готово |
| Заблокирована | Открыта |
| Готово | Открыта |

Сохранение текущего статуса считается правкой без перехода. При смене статуса `Task::revise()` проверяет правило enum. Запрещённый переход выбрасывает `DomainException` и возвращает HTTP 422 без сохранения изменений.
