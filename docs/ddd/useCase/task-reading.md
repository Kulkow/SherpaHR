# Чтение задач

## UC-02 · Просмотреть задачи проекта

**Актор:** выбранный демо-пользователь, состоящий в проекте. **Триггер:** выбор проекта или его автоматическое открытие после UC-01.

1. Angular очищает карточку, фильтры и предыдущий список. Запрашивает `GET /api/projects/{id}/tasks`.
2. PHP проверяет членство и возвращает 200 со строками по возрастанию ID.
3. Интерфейс показывает название, статус, исполнителя и срок UTC. Пользователь может искать подстроку в названии без учёта регистра и одновременно ограничить список одним статусом. Фильтры применяются в браузере.
4. При отсутствии подходящих строк интерфейс показывает пустой результат. При ошибке запроса отображается общий баннер, а таблица также может показать пустой результат.

**Отклонения и ограничения:** недоступный проект возвращает 404. Архив доступен для чтения. Список включает задачи без исполнителя. [Запросы SQLite](../../../backend/src/Infrastructure/Sqlite/ProjectDeskQueries.php).

## UC-03 · Открыть карточку и прочитать обсуждение

**Актор:** участник проекта задачи. **Триггер:** выбор строки задачи.

1. Angular запрашивает `GET /api/tasks/{id}`.
2. PHP проверяет членство в проекте задачи и возвращает 200 с полями задачи и массивом `comments`. Имена авторов добавляются из каталога пользователей, комментарии упорядочены по ID.
3. Интерфейс заполняет карточку. В обсуждении видны авторы, время UTC и текст. При пустом массиве показано сообщение об отсутствии комментариев.
4. В активном проекте доступны редактирование и форма комментария. В архиве поля отключены, операции записи скрыты. Карточку можно закрыть и вернуться к списку.

**Альтернативы:** отсутствующая или недоступная задача даёт 404. Чтение не меняет данные.

Источники: [Прикладные операции](../../../backend/src/Application/ProjectDeskUseCases.php), [app.ts](../../../frontend/src/app.ts#L69-L119), [app.html](../../../frontend/src/app.html#L23-L68).
