# Создание и редактирование задач

Допустимые текущие статусы: `open`, `in_progress`, `blocked`, `done`. Допустимые смены статуса перечислены в [матрице переходов](../entity-vo/value-objects.md#переходы-taskstatus). Запрещённый переход даёт 422. Сохранение прежнего статуса считается редактированием без перехода. Исполнитель может отсутствовать или быть участником проекта. Срок передаётся в UTC с секундами или `null`.

## UC-04 · Создать задачу

**Актор:** участник активного проекта. **Триггер:** кнопка «Новая задача».

1. Интерфейс открывает пустую форму со статусом `open`. Пользователь вводит обязательное название и при необходимости описание, исполнителя и срок. Статус новой задачи — «Открыта».
2. Angular отправляет `POST /api/projects/{id}/tasks`. PHP проверяет проект, членство, архив и поля.
3. SQLite сохраняет задачу с новым ID, версией 1 и серверным временем обновления. Сервер возвращает 201 и сохранённую задачу.
4. Интерфейс добавляет задачу в текущий список, увеличивает счётчик и оставляет карточку открытой.

**Альтернативы:** пустое название, неверный статус, дата или исполнитель вне проекта дают 422. Чужой проект даёт 404, архив — 409. Задача без исполнителя доступна после повторной загрузки списка.

## UC-05 · Изменить задачу

**Актор:** участник активного проекта с открытой карточкой. **Триггер:** сохранение формы.

1. Пользователь изменяет поля задачи. Angular отправляет `PATCH /api/tasks/{id}` с полями черновика и текущей `version`.
2. PHP проверяет членство и архив проекта, валидирует поля и целочисленную версию. Для прямого частичного запроса отсутствующие поля остаются прежними.
3. SQLite применяет изменение только при совпадении версии. Сервер обновляет `updated_at`, увеличивает версию и возвращает 200 с сохранёнными полями.
4. Интерфейс обновляет список и текущую карточку. Имеющиеся комментарии и несохранённый текст нового комментария сохраняются в открытой форме.

**Альтернативы:** чужая задача даёт 404, архив или конфликт версии — 409, ошибка полей или отсутствующая версия — 422. При конфликте интерфейс показывает сообщение с предложением открыть задачу заново. У текущей формы точность срока до минуты, поэтому сохранение может сбросить его секунды. В API явный `null` очищает срок или назначение. Для статуса и описания он даёт 422.
