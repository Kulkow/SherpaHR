## Общие правила

- Заголовок `X-Demo-User` выбирает пользователя. По умолчанию используется Анна. Неизвестный ID возвращает 401. Это локальный демо-режим.
- Доступ к проектам и задачам проверяется по членству. Отсутствующий и недоступный объект возвращают 404. У руководителя те же проверки членства.
- Архив доступен для чтения его участникам. Изменения в архиве возвращают 409.
- Успех передаётся как `{"data": ...}`, ожидаемая ошибка — как `{"error": "..."}`. Запись принимает JSON-объект до 32 KiB, некорректный JSON даёт 400, превышение размера — 413.
- Правила ниже сверены со [справкой API](../../api.md), [HTTP-контроллерами](../../../backend/src/Http/FrontController.php) и [Angular-компонентом](../../../frontend/src/app.ts). Бизнес-термины соответствуют [доменной модели](../entity-vo/README.md).
