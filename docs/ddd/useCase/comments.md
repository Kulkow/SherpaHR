# Комментарии

## UC-06 · Отправить комментарий

**Актор:** участник активного проекта с открытой карточкой. **Триггер:** кнопка «Добавить комментарий».

1. Пользователь вводит текст. Кнопка недоступна для пустого текста и во время сохранения.
2. Angular отправляет `POST /api/tasks/{id}/comments` с JSON-объектом `{"body":"текст"}`. Если установлен флажок, запрос также содержит `requires_attention: true`.
3. PHP проверяет доступ к задаче и архивность проекта, затем валидирует тело. Поле `body` должно быть строкой с непустым содержимым после обрезки. Предел API — 5000 байт UTF-8 до обрезки.
4. Прикладная операция создаёт комментарий от имени выбранного пользователя, сохраняет его с серверным временем UTC и возвращает 201 с данными записи. Версия задачи сохраняется.
5. Angular добавляет запись в открытое обсуждение и очищает поле ввода. При ошибке текст остаётся в поле. После повторного открытия комментарий доступен через [UC-03](task-reading.md).

## Обработать отметку внимания

Текущий руководитель активного проекта нажимает «Отметить обработанным». Angular отправляет
`POST /api/tasks/{taskId}/comments/{commentId}/resolve`. API проверяет членство и роль руководителя,
переводит отметку в `resolved` и возвращает 200. Повторный запрос возвращает тот же результат.
Обзор обновляется. Если у задачи есть другие причины внимания, она остаётся в списке.

**Альтернативы:** участник без роли руководителя получает 403 при попытке обработать отметку. отсутствующая или недоступная задача возвращает 404, архив — 409, некорректное поле `body` — 422. Общие ошибки JSON и размера запроса описаны в [каталоге](README.md).
