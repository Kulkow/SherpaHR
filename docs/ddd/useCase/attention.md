# UC-07 · Посмотреть обзор «Требуют внимания»

**Актор:** текущий руководитель активного проекта, состоящий в проекте.

1. После выбора пользователя с такими проектами интерфейс открывает обзор. Из бокового меню к нему можно вернуться.
2. `GET /api/attention` выбирает подходящие задачи всех исполнителей и задачи без назначения. Одна строка показывает проект, задачу, срок и все причины отбора.
3. Руководитель открывает карточку в контексте проекта, читает полное обсуждение, отвечает, меняет задачу или обрабатывает отметку комментария.
4. После сохранения или обработки отметки обзор обновляется, сохраняя открытую карточку. Если у задачи больше нет причин, она исчезает из обзора.

Завершённая задача появляется в обзоре при активной отметке комментария. Архивные и чужие проекты исключены. Если подходящих задач нет, отображается пустое состояние. [Контракт API](../../api.md), [обработка отметки](comments.md).
