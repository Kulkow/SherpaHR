# Транзакции и проверки

Прикладная операция определяет границы транзакции. Участвующие репозитории используют один PDO. При совместной записи и чтении результата применяем одну транзакцию или возвращаем изменённую строку из операции записи.

| Операция | Последовательность и гарантия |
|---|---|
| Создать задачу | Найти доступный проект, проверить архивность и членство исполнителя, записать задачу с версией 1 и вернуть созданную строку |
| Изменить задачу | Найти задачу, проверить доступ, архив и поля, применить изменения через условие по ID и ожидаемой версии. Обновление увеличивает версию на 1. Если условие версии не выполнено, вернуть конфликт и сохранить ранее записанные данные |
| Добавить комментарий | Найти задачу, проверить доступ и архив, записать комментарий с текущим автором и временем и вернуть сохранённую запись. Поля и версия задачи сохраняются |
| Прочитать карточку или обзор | Выполнить запрос с ограничениями доступа. Если карточка собирается несколькими запросами и нужен единый снимок задачи и переписки, использовать транзакцию чтения |

Если проект, членство или задача могут измениться параллельно, проверка изменяемых условий и запись выполняются атомарно. Для SQLite можно использовать короткую транзакцию записи, которая получает блокировку до чтения этих условий, или условие непосредственно в SQL записи. В текущем v7 состав и архив фиксированы. Версия задачи уже защищает обновление от потери изменений. Старт и миграции БД выполняются отдельно от рабочих операций. [Архитектура backend](../../architecture/implementation.md), [прикладные операции](../../../backend/src/Application/ProjectDeskUseCases.php).

## Интеграционные проверки на временной SQLite

- Создание и чтение задачи без исполнителя: `NULL` сохраняется, задача доступна в списке.
- Две попытки изменения с одной версией: первая сохраняется, вторая получает конфликт, итоговые поля соответствуют первой.
- Добавление комментария: возвращённые автор, текст и время совпадают с записью, карточка показывает комментарий, версия задачи прежняя.
- Права: чужой проект и его карточка скрыты, архив читается, запись в архив отклоняется, исполнитель вне проекта не принимается.
- Обзор на фиксированном времени: задача с двумя причинами появляется один раз; завершённые задачи, чужие и архивные проекты исключены.
