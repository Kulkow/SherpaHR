# Границы контекста Project Desk

Проекты, пользователи демо, задачи и обсуждения входят в один bounded context Project Desk. Они используют общий словарь и работают в одной SQLite. В доменном коде папки `Project`, `Task` и `User` группируют модели этого контекста.

Проект определяет членство, владельца и архивность. Задача определяет рабочий статус, переходы и версию. Комментарий живёт в области задач как отдельный агрегат с собственной отметкой внимания. Адресат отметки вычисляется по текущему владельцу проекта.

Обзор «Требуют внимания» читает данные этих агрегатов. Он не хранит собственное состояние задач. Граница с Angular проходит через [OpenAPI](../../contracts/openapi.yaml). Рабочая аутентификация и управление проектами или пользователями остаются за пределами демо. [Агрегаты](entity-vo/aggregates.md), [репозитории](repositories/README.md).
